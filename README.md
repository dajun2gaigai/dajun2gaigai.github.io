# dajun2gaigai.github.io

Personal academic website of Jianjun Chen (陈建军), built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme.

## Research Interests

- Cooperative Perception for Autonomous Driving
- Federated Learning
- V2V Communication
- Robot Learning & Embodied AI
- 3D Gaussian Splatting
- Vision-Language-Action (VLA) Models

## Local Development

```bash
# Using Docker (recommended)
docker-compose up

# Or using Ruby directly
bundle install
bundle exec jekyll serve
```

Visit `http://localhost:8080` to preview the site.
